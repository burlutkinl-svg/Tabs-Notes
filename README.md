Для запуска бэкенда(cmd):

pip install -r requirements.txt
cd backend
uvicorn main:app --reload

Бэкенд работает по адресу http://127.0.0.1:8000

Для запуска фронтенда(cmd):

python run.py

Фронтенд работает по адресу http://127.0.0.1:5000
